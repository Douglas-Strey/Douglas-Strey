# Embedded typeface

The SVG assets in this directory embed a subset of **Geist Mono**, limited to the
glyphs they actually use (~5 KB per weight). Embedding it means the lettering
renders identically for every visitor instead of falling back to whatever
monospace font their machine happens to have.
